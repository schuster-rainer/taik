Build an isometric floor planner for a fictional 24 by 18 tile ALDI-style discount supermarket.

Deliver one offline standalone HTML document titled "TAIK · Isometrischer Marktplan". Create a distinctive native-feeling working space: dominant isometric Canvas or authored geometric SVG plan on the left, a narrow responsive "Einrichtung" sidebar on the right, with text labels and fixtures editable by actual selection and keyboard/buttons. Show the entrance, exit, walkable route, shelves, produce, bakery, refrigeration and checkout. Draw raised fixtures, accessible labels and restrained color. Use German text. Render responsive without assets or dependencies. Use modern browser support. Aim for 9–14 KB of HTML, CSS and JS.

Contract for the independently executed verifier: put a pure script in exactly <script id="layout-model">. Set globalThis.floorPlan = { initial, validate, move, project, unproject }.
